# Project Instructions

## Objective
Develop a polished browser-based turn-based strategy game.

## Before editing
- Inspect relevant files and dependencies.
- Identify existing conventions and reusable functions.
- Explain major architectural changes before implementing them.

## Implementation standards
- Preserve existing working features.
- Prefer small, maintainable changes.
- Avoid unnecessary dependencies.
- Keep gameplay logic separate from presentation.

## Map generation
- Ensure balanced player starting conditions.
- Provide viable freshwater access.
- Avoid unfair continent and archipelago starts.
- Maintain coherent landmasses and mountain ranges.

## Testing
- Run relevant existing tests.
- Add regression tests when fixing bugs.
- Verify multiple map seeds and sizes.
- Report failures and unverified behavior.

## Communication
- Summarize changed files and decisions.
- Identify limitations and remaining risks.
- Do not claim features work without testing.
